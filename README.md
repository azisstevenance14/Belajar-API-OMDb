# 🎬 ASSA Movie Search App

Aplikasi web pencari film interaktif berbasis **Vanilla JavaScript** yang memanfaatkan **OMDb API** untuk mengambil data film secara *real-time*. Project ini dibangun sebagai bagian dari eksplorasi arsitektur frontend, *DOM manipulation*, dan *Async/Await* dalam pengembangan web modern.

---

## 🚀 Fitur Utama
* **Pencarian Film Real-Time**: Cari judul film apa saja (contoh: *Batman*, *Spider-Man*, *Naruto*, dll).
* **Responsive Grid Layout**: Tampilan kartu film yang rapi dan adaptif menggunakan **Bootstrap 5.3**.
* **Dynamic DOM Manipulation**: Menampilkan hasil pencarian, poster, tahun rilis, dan tipe film secara otomatis dari data JSON.
* **Error Handling & Loading State**: Dilengkapi *spinner* saat proses *fetching* data dan penanganan pesan jika film tidak ditemukan atau koneksi terputus (`try...catch`).

---

## 🛠️ Teknologi yang Digunakan
* **HTML5 & CSS3** (Struktur & Styling dasar)
* **Bootstrap 5.3 CDN** (Framework UI responsive)
* **JavaScript (ES6+)** (`async/await`, `fetch`, DOM API, Event Listener)
* **OMDb API** (Sumber data film eksternal)
